# Hautpocket — 河南工业大学教务口袋助手 (Android + Flutter)

本项目为针对**河南工业大学正方教务管理系统（N9/V9.0，`http://jwglxt.haut.edu.cn/`）**与**《人工智能专业-河南工业大学2025版专业人才培养方案》**定制开发的 Android + Flutter 客户端工程。

## 一、核心功能架构

1. **教务系统登录与自定义间隔自动同步**
   - 默认预置学号 `251210100701` 与密码 `Csy1230！`（自动兼容全角 `！` 与半角 `!` 容错重试）。
   - 支持用户自定义后台自动更新间隔（15 分钟、30 分钟、1 小时、6 小时、12 小时、24 小时或自定义分钟数）。
2. **第一页：今日课表 + 每周课表查询 + 双模式上课提醒**
   - 主页展示**今日课程安排**（课程名称、节次起止时间、莲花街校区教室地点、任课教师）与**第 1~20 周完整周课表**。
   - 支持**推送消息提醒（Push Notification）**与**系统闹钟提醒（System Alarm Clock）**两种方式自由切换或同时开启，可设置提前 10/15/30 分钟提醒。
3. **第二页：选课查询 + 培养方案类目学分要求 + 未选可选课程按学分大小分类**
   - 严格依据《人工智能专业-河南工业大学2025版专业人才培养方案》，内置全部 **95 门课程**与四大平台学分要求（通识平台 `48.5` 学分、学科平台 `44.5` 学分、专业平台 `62.0` 学分、能力拓展 `14.0` 学分，总计 `169.0` 学分）。
   - 未选但之后还可以选的课程支持按**学分大小分类**（`7.5 学分`、`6.0 学分`、`4.0 学分`、`3.0 学分`、`2.5 学分`、`2.0 学分`、`1.0 学分`、`0.5~0.2 学分`）及按平台/性质筛选。
4. **第三页：单科学分绩点与总学分绩点计算 + 毕业培养方案学分差额核算**
   - 按照河南工业大学 5.0 制标准计算每门已出分课程的**单科绩点 ($GP_i$)**、**单科学分绩点 ($C_i \times GP_i$)**、**总学分绩点 ($\sum C_i GP_i$)** 与**加权平均学分绩点 (GPA)**。
   - 自动核算距离培养方案毕业标准（总计 `169.0` 学分，其中必修课 `137.0` 学分、选修课 `32.0` 学分）以及四大平台各模块还需修读多少学分。

## 二、如何一键编译生成 `Hautpocket.apk`

### 方法 A：本地一键打包（Windows / macOS / Linux）
- **Windows**：双击运行工程根目录下的 `build_apk.bat`
- **macOS / Linux**：在终端执行 `bash build_apk.sh`
- 编译完成后，APK 位于：`build/app/outputs/flutter-apk/app-release.apk`

### 方法 B：免配环境 — 使用内置 GitHub Actions 云端自动打包 APK
本工程已内置 `.github/workflows/build_apk.yml` 云端打包流水线：
1. 将本工程上传至任意 GitHub 仓库（公开或私有均可）。
2. 点击仓库顶部的 **Actions** -> **Build Hautpocket Android APK** -> **Run workflow**。
3. 等待约 3 分钟即可在页面底部 **Artifacts** 下载编译好的 `Hautpocket-release-apk.zip`（内含 `app-release.apk`），直接安装到安卓手机即可！
