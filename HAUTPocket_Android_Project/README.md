## 小白免装软件 3 分钟云端生成手机 `.apk` 教程
1. 解压本压缩包，得到里面的所有文件夹和文件（`.github`、`app`、`build.gradle.kts`、`settings.gradle.kts` 等）。
2. 上传到你新建的 GitHub 仓库根目录并点击 **Commit changes**。
3. 点击仓库顶部的 **Actions** 标签页，等待 2~3 分钟变成绿色对勾 ✅ 后，点进去滑到最底部点击 **`HAUTPocket-v0.32.0-debug-apk`** 即可下载装进手机！
